# Solynx Innovations

Official website for **Solynx Innovations** — a premium, futuristic technology company site built as a static experience.

## Stack

- HTML5
- CSS3 (custom design system)
- Vanilla JavaScript
- Bootstrap 5 (grid, navbar utilities, forms)
- Canvas API (particles)
- SVG

## Structure

```
├── index.html              Home
├── about.html
├── services.html
├── solutions.html
├── portfolio.html
├── technologies.html
├── careers.html
├── contact.html
├── quote.html
├── *-development.html      Individual service pages
├── project-*.html          Project case studies
├── css/                    Design system
└── js/                     Modular interaction layer
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
